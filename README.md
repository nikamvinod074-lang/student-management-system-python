# Student Management System

A console-based Student Management System developed using Python.

## Features
- Add Student
- View All Students
- Search Student
- Update Student Details
- Delete Student
- Calculate Grade
- Input Validation
- Exception Handling

## Technologies Used
- Python
- Functions
- Dictionaries
- Match Case
- Exception Handling

## How to Run

1. Install Python
2. Download the project
3. Open Command Prompt
4. Run:

python StudentManagementSystem.py
